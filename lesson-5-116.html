Множество. Элементы множества. Изображение множеств

Для игры включи JavaScript. Объяснения ниже доступны без него.

🖨 Карточка для работы на бумаге
📖 Изучи тему: правило и пример
  1. Множество — совокупность элементов. Записываем элементы в фигурных скобках без повторений.
  2. ∈ — принадлежит, ∉ — не принадлежит, ∅ — пустое множество.
  3. A ∩ B — общие элементы. A ∪ B — элементы хотя бы одного множества.
  4. C ⊂ A: каждый элемент C входит в A; в наших примерах C отличается от A.
A = {1, 2, 3}, B = {3, 4}

A ∩ B = {3}; A ∪ B = {1, 2, 3, 4}. Элемент 3 в объединении пишем один раз.

🎒 Самостоятельная практика

Реши три задания в тетради. Открывай подсказку, если нужна помощь, а ответ — после своей попытки.

  1. A = {5, 6, 7}, B = {7, 8}. Выбери все общие элементы.

    Карточки: 5; 6; 7; 8

    Подсказка

    Пересечение A ∩ B содержит общие элементы.

    Сверь ответ

    7

    Все нужные карточки выбраны.

  2. Собери A ∪ B для A = {5, 6, 7}, B = {7, 8}.

    Карточки: 5; 6; 7; 8; 10

    Подсказка

    В объединение входят элементы хотя бы одного из множеств.

    Сверь ответ

    5; 6; 7; 8

    Все нужные карточки выбраны.

  3. Является ли {5, 6} подмножеством {5, 6, 7}?

    Карточки: Да; Нет

    Подсказка

    Каждый элемент подмножества должен входить в исходное множество.

    Сверь ответ

    Да

    Верно: Да.
