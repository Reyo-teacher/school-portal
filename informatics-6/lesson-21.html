Теория

9 мин

Сложение, вычитание, умножение

Python использует +, - и *. Например, 18 + 3 * 4 даёт 30: сначала умножение, потом сложение.

Степень и скобки

Запись 2 ** 3 означает 2 в третьей степени. Скобки меняют порядок: (18 + 3) * 4 и 18 + 3 * 4 дают разные результаты.

Три операции деления

Для положительных целых / делит без отбрасывания дроби, // даёт целое частное, а % даёт остаток. Например, 17 / 5 = 3.4, 17 // 5 = 3, 17 % 5 = 2.

Разбор

6 мин

Игровые баллы

Команда заработала 18 очков, затем трижды получила по 4, добавила бонус 2³ и потеряла 5. В примере итог 33. Для четырёх игроков программа показывает среднее 8.25, 8 целых баллов на игрока и 1 оставшийся балл.

start = 18
rounds = 3
per_round = 4
bonus = 2 ** 3
penalty = 5
players = 4

score = start + rounds * per_round + bonus - penalty
print("Итог:", score)
print("Среднее:", score / players)
print("Целых каждому:", score // players)
print("Остаток:", score % players)

Запусти пример в установленном Python 3. На этой странице код не выполняется.
