# Расширение интерактивного курса 5 класса

Источник последовательности и целей — `data/grade-5-curriculum.json`, перенесённый
из КТП учителя. Учебник: Алдамұратова и соавторы, Атамұра, 2017, части 1–2.
Задания написаны для сайта; страницы учебников указаны для самостоятельного чтения.

`data/grade-5-games.json` перечисляет уроки, в которых опубликован игровой маршрут.
Уроки 4 и 5 сохраняют исходные адреса и собственные игры. Новые маршруты строятся
из модулей `scripts/course/` командой `python scripts/build_course.py НОМЕРА`.
Основной генератор `scripts/build_grade5.py` сохраняет эти маршруты при пересборке.

Каждый новый урок содержит шесть шагов и три варианта, объяснение, разобранный
пример, задание в тетради и точные цели КТП. Основные действия: выбор, числовой
ответ, упорядочивание, выделение частей и построения. Последний шаг предназначен
для самостоятельной попытки; вывод об освоении делает учитель по объяснению.

СОР/СОЧ представлены тренировкой, а не официальным оценочным пакетом. Страницы
анализа предлагают повторную практику после обсуждения реальных ошибок с учителем.
Игровые звёзды не переводятся в отметку. Озвучка использует существующий модуль
`lesson-voice.js`. Данные жизненных задач условные.

Проверки: `node --test tests/*.test.js`, `python -m unittest discover -s tests -v`,
проверка манифестов и ресурсов HTML. Проверяются корректные и ошибочные ответы,
форматы дробей, варианты, уникальность заданий и соответствие страниц каталогу.
Реальный браузерный прогон и прослушивание в этой среде недоступны; тесты с
подменой DOM/API не подтверждают внешний вид и звучание на устройстве.

## Работа без интернета

Печатный шаблон `lesson-practice.js/.css` обновлён по двум файлам, присланным
учителем после доработки в Claude. Сохранены рабочая карточка, лист ответов,
место для решения, самостоятельная работа, номер варианта и смена всех
заданий. В первых двух тренажёрах запись числа с лишним нулём слева теперь
требует исправления. Оценка времени на карточке ориентировочная, не результат
апробации. Кнопка PDF открывает системное окно печати, где можно сохранить PDF.

`course-print.js` применяет этот же макет к новым урокам: условия, рисунки,
правила, пример, самостоятельная работа и отдельные ключи. Ученический лист
не содержит выделенных ответов. Карточка и ключ используют один номер варианта.
СОР/СОЧ маркируются как подготовка, а не контрольная работа. Новый вариант
получают повторным прохождением игры; ответы печатают до смены варианта.
