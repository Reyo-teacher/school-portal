# Дополнение двух исходных уроков математики

Страницы `topic-5-1-1.html` и `topic-5-1-2.html` остаются уроками 4 и 5
в каталоге из 170 часов. Цели взяты из КТП учителя; ссылки на параграфы —
из используемого учебника Алдамұратовой и соавторов, часть 1, 2017.

Первый урок дополнен различием цифры и числа, чётностью через пары,
объяснением роли нуля, учебными чеками в тенге и самостоятельной проверкой.
Второй — единицами длины, изменением единичного отрезка, конструктором луча,
различием координаты и расстояния и самостоятельным построением в тетради.
Схема дороги, робототехника, переработка и датчик полива используют условные
данные. Углублённые задания открываются отдельно от основной практики.

## Игровой вход для первого знакомства

При открытии каждого урока сначала показывается короткое приглашение в игру.
Шесть шагов раскрываются по одному: счёт и пары для натуральных чисел;
начало луча, перемещение, чтение координаты, построение и изменение единичного
отрезка для второго урока. Большие числа, много полей и подробные объяснения
не показываются на первом экране. Справочник и дополнительный тренажёр
свёрнуты в отдельные доступные без JavaScript блоки `details`.

`lesson-adventure.js` и `lesson-adventure.css` содержат игровой маршрут.
Он предлагает три варианта с небольшими числами, подсказки без штрафов,
финальное самостоятельное действие и повторную игру. Звёзды отражают
завершённые шаги, не отметку и не освоение. Только завершённые шаги хранятся
в `portal_adventure_naturals_v1` и `portal_adventure_ray_v1`; общее XP
и учёт умений дополнительного тренажёра от них не меняются. При перезагрузке
незавершённый шаг начинается заново, завершённые сохраняются.

## Озвучка совы

`lesson-voice.js` использует Web Speech API: `speechSynthesis` и
`SpeechSynthesisUtterance`. Обе страницы загружают его перед игровым модулем.
Звук не запускается при загрузке страницы: первое чтение происходит по
действию ребёнка. Автоматическое чтение включено по умолчанию после старта
игры; его можно отключить. «Послушать» повторяет текущую инструкцию, «Стоп»
останавливает речь, темп переключается между 0.95 и 0.8.

Речь собирается из текущего задания и вариантов ответа. Закрытые подсказки,
ответы и описания изображений с готовым результатом в неё не попадают.
Открытая подсказка, текущий этап построения и обратная связь читаются
отдельно. Обозначения A(3), O(0), B(2), OA, см и знаки действий преобразуются
в произносимый русский текст. Повторное чтение не считается учебной помощью.

Каждый новый текст отменяет предыдущий; устаревшие события речи игнорируются.
При уходе со страницы или скрытии вкладки речь прекращается. Русский голос
выбирается из голосов устройства, предпочтение отдаётся локальному. Список
голосов может появиться позже; обрабатывается `voiceschanged`. При отсутствии
API, русского голоса или разрешения воспроизвести звук остаются текстовые
задания и понятное сообщение. Микрофон не запрашивается. Наличие русского
голоса и его звучание зависят от браузера и ОС; офлайн-работа сетевых голосов
не гарантируется. Настройки находятся в `portal_owl_voice_v1`.

Источники API: [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis),
[getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices),
[Web Speech API](https://webaudio.github.io/web-speech-api/).

## Проверка и обратная связь в дополнительной практике

В тренажёрах 11 и 10 типов заданий с генерируемыми вариантами. Проверка
многополевого задания требует и ответа, и выбранного основания. Неверный
ответ сопровождается подсказкой; можно исправить его и перейти к новому
примеру. Пустой или неверно оформленный ввод не считается попыткой.
Отчёт по умениям различает решения без помощи и с опорой. Он не утверждает,
что умение освоено, и не заменяет наблюдение учителя.

Итоговые задания сохраняют первую попытку в памяти открытой страницы.
Чертёж в тетради проверяет учитель. Ключи и критерии вынесены в открытую
страницу `teacher-grade5-lessons.html`. Это учебная практика, а не защищённая
контрольная работа. Печатный лист тренажёра не содержит ключей.

## Совместимость

Новые `lesson-practice.js`, `lesson-widgets.js` и `lesson-practice.css`
используются только двумя обновлёнными страницами. Общий `portal.js`
и другие темы не изменены. Старые общие игровые очки
`portal_logunov_1_1_xp` сохранены и явно отделены от учебных результатов.
Новые ключи `portal_logunov_naturals_skills_v2` и
`portal_logunov_ray_skills_v2` содержат только локальные сведения о вариантах
и помощи; имена и ответы учеников не отправляются на сервер.

## Выполненные проверки

```sh
node --test tests/practice-math.test.js tests/adventure.test.js tests/voice.test.js
python -m unittest discover -s tests -v
node --check lesson-practice.js
node --check lesson-widgets.js
node --check lesson-adventure.js
node --check lesson-voice.js
git diff --check
```

Node проверяет случайные и граничные варианты генераторов, неверные и пустые
ответы, контекстные вычисления, единицы, построение луча и повторный зачёт.
Тесты маршрута проверяют три варианта каждого урока, пары, единицы,
исправление ошибки, прохождение, повторную игру и восстановление прогресса.
Проверка контроллера использует заглушку DOM и не заменяет браузер.
Тесты озвучки подменяют Web Speech API: проверяются тексты всех вариантов,
выбор русского голоса, отмена и устаревшие события, ошибки, повторное чтение,
настройки и остановка при скрытии страницы. Реальное звучание не прослушано.
Python проверяет каталог, соответствие КТП и навигацию всех 170 уроков.
Манифесты `data/practicum/naturals.json` и `ray.json` прошли проверку структуры
и наличия ресурсов HTML. Существующая загрузка шрифта Google требует сети;
при её отсутствии применяется запасной шрифт.

Браузерная проверка не выполнена: среда запрещает создание сокета Chromium.
Поэтому автоматические проверки не подтверждают внешний вид, печать и
пользовательские взаимодействия в реальном браузере. В браузере следует
проверить мобильную ширину, управление конструктором с клавиатуры, печать,
перезагрузку страницы и восстановление локального отчёта.
