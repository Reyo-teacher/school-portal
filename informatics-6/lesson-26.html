Теория

9 мин

Три вида деления

Для положительных целых: 17 / 5 = 3.4, 17 // 5 = 3, 17 % 5 = 2. / даёт обычное частное, // — сколько целых групп, % — остаток.

Порядок действий

** — возведение в степень; затем выполняются *, /, // и %, после них + и −. Скобки позволяют явно задать порядок: (2 + 3) * 4 даёт 20.

Проверка по случаям

Сначала предскажи результат, затем запусти. Проверь обычное число, точное деление и ноль в делимом. Если результат другой, проверь знак операции и скобки.

Разбор

6 мин

Журнал проверки

Для n = 17, k = 5 программа выводит 22, 12, 85, 25, 3.4, 3, 2. Проверяем, что 17 = 3 × 5 + 2.

n = 17
k = 5
print("Сумма:", n + k)
print("Разность:", n - k)
print("Произведение:", n * k)
print("Квадрат делителя:", k ** 2)
print("Частное:", n / k)
print("Полных групп:", n // k)
print("Остаток:", n % k)

Запусти пример в установленном Python 3. На этой странице код не выполняется.

Если нет нужной программы

Прогони операции на бумаге. Подобрать целую часть и остаток можно повторным вычитанием делителя, пока следующее вычитание не сделает результат отрицательным.

Составь пример, где / и // показывают одинаковую числовую величину, но имеют разный вид: например 4.0 и 4.
