# Математика, 5 класс: структура по КТП 2026–2027

Каталог `grade-5.html` содержит 170 уроков по приложенному учителем файлу
«КТП_математика_5_класс.docx». У каждого часа собственная страница
и переходы к предыдущему и следующему уроку. Уроки 4 и 5 открывают существующие
лекции с тренажёрами напрямую; остальные уроки используют страницы
`lesson-5-NNN.html` с темой, целью, четвертью и материалами.
Страницы открываются без JavaScript.
JavaScript в каталоге добавляет поиск, фильтр четверти и переключение вида.

## Источник и неоднозначности

- Использован подробный план: во второй таблице DOCX 170 одночасовых строк.
  В сводной таблице отдельно указано фактическое количество 165; календарные
  даты в подробном плане пусты. Каталог отражает плановые 170 часов, даты не добавлены.
- `sourceRow` — индекс строки второй таблицы, начиная с нуля и включая заголовки.
  `sourceTopic`, `sourceObjective`, `sourceSection` сохраняют исходный текст
  ячеек для сверки. Пустые ячейки раздела на умножении и делении дробей
  продолжают раздел «Действия над обыкновенными дробями».
- Повторяющиеся темы не объединены в один урок. Добавлены номер занятия
  и количество часов по теме. Длинные объединённые заголовки СОР сохранены
  в раскрываемом блоке «Тема по КТП»; отметки СОР на уроках взяты только
  из графы «Примечание». Поэтому СОР не дублируются на каждой строке темы.
- Урок 86 (строка 90) содержит одновременно СОР № 6 в примечании и анализ
  его результатов в цели. Обе отметки сохранены в одном часе.
- На уроках 160–162 в исходнике пропущена начальная цифра кода `.3.2.1`.
  В отображаемой цели восстановлено `5.3.2.1` по предыдущей строке; исходный
  текст оставлен в `sourceObjective`.
- Знаки сравнения и множеств были изображениями в Word. Они проверены визуально
  и перенесены текстом: `>, <, =`, `∪, ∩, ∈, ∉, ⊂, ∅`, `∪, ∩`.
- Темы старого каталога, отсутствующие в приложенном КТП (например, отрицательные
  числа, пропорции, координаты на плоскости), убраны из структуры 5 класса.

## Учебники и существующие материалы

Т. А. Алдамұратова, К. С. Байшоланова, Е. С. Байшоланов. «Математика.
5 класс». Части 1 и 2. Алматы, «Атамұра», 2017.
Соответствия параграфов и печатных страниц проверены по оглавлениям:
часть 1 — с. 221–222, часть 2 — с. 190–191.
Это рекомендуемые ссылки по теме, а не назначенные учителем номера упражнений.
PDF учебников не публикуются в репозитории.

Существующие страницы `topic-5-1-1.html` и `topic-5-1-2.html` являются
основными страницами уроков 4 и 5. Каталог и соседние уроки открывают их напрямую.
По запросу учителя содержание этих двух лекций и тренажёров дополнено;
адреса, навигация и прежние общие игровые очки сохранены. Учёт умений хранится
отдельно для каждого урока. Подробности — в `grade-5-lesson-upgrade.md`. Адреса `lesson-5-004.html` и `lesson-5-005.html` автоматически
переводят на соответствующие исходные страницы и содержат запасную ссылку.
Поле `contentPage` в JSON задаёт исходную страницу для таких уроков, а `url`
сохраняет адрес совместимости. Генератор обновляет в исходных страницах только
блок навигации между маркерами `grade5-navigation:start/end`.
Адрес `grade-5.html#ch1` по-прежнему ведёт в раздел натуральных
чисел. Остальные страницы уроков содержат тему, цели и указания к учебнику;
полные лекции, новые тренажёры и варианты СОР/СОЧ этой задачей не создавались.

## Обновление

1. Изменить `data/grade-5-curriculum.json`.
2. Выполнить `python3 scripts/build_grade5.py`.
3. Выполнить `python3 -m unittest discover -s tests` и `node --check grade-5.js`.
4. Проверить каталог и страницы в браузере, затем сохранить JSON и сгенерированные HTML вместе.

У проекта нет сборки на сервере: GitHub Pages публикует готовые HTML, CSS и JS.
