Теория

9 мин

Диалог с программой

input('Подсказка: ') выводит подсказку и ждёт одну строку до нажатия Enter. Ответ сохраняют в переменной.

Текст или число?

input() всегда даёт строку. Сложение строк '4' + '5' соединяет символы. Для вычислений целое число получают через int(), дробное — через float().

Что вводить

Для int() пиши целое, например 4. Для float() используй точку: 2.5. Если текст не похож на нужное число, Python сообщает об ошибке преобразования.

Разбор

6 мин

Два числа, один результат

Введи 3 и 4 на отдельных строках. Переменные получают числа, поэтому программа выводит «Всего деталей: 7». Вводим учебные данные, не имена и не телефоны.

a = int(input("Деталей в первом наборе: "))
b = int(input("Деталей во втором наборе: "))
print("Всего деталей:", a + b)

Проверь похожий код в браузерной лаборатории ниже. Скачивать пример не обязательно.
