Теория

9 мин

Что обозначают /, // и %

Для неотрицательного целого count и положительной целой вместимости size выражение count / size даёт обычное частное, count // size — число полных коробок, count % size — число оставшихся предметов.

Проверка результата

Должно выполняться count = size × полные коробки + остаток, а остаток меньше size. Это быстрый способ проверить, не перепутаны ли частное и остаток.

Неполная коробка

Когда остаток положителен, для него нужна ещё одна коробка. При нулевом остатке добавлять коробку не нужно. Не используй нулевую вместимость: на ноль делить нельзя.

Разбор

6 мин

Упаковка значков

53 // 8 даёт 6 полных коробок, 53 % 8 даёт 5 значков. Проверка: 8 × 6 + 5 = 53. Для всех значков нужна ещё одна, седьмая, коробка.

count = 53
size = 8

full = count // size
left = count % size
print("Обычное частное:", count / size)
print("Полных коробок:", full)
print("Осталось значков:", left)
print("Проверка:", full * size + left)
